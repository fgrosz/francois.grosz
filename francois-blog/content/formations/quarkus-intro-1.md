## Qu'est-ce que Quarkus ?

Quarkus est un framework Java cloud-native conçu pour les JVM GraalVM et HotSpot.

## Pourquoi Quarkus ?

- Démarrage en millisecondes
- Empreinte mémoire réduite
- Developer experience moderne

## Installation

```bash
sdk install quarkus
quarkus create app org.example:my-app
cd my-app
quarkus dev
```
